# rust-videos（暴风影音）

用 Rust 实现的类「暴风影音」视频播放器，基于 [rust-photos](https://github.com/setsuodu/rust-photos) 改造。目标是提供带播放列表的本地视频播放体验。

当前仍处于从照片查看器迁移的阶段，核心播放与 UI 骨架已可用，播放列表等功能按下方需求迭代。

## 安装（推荐）

到 [Releases](https://github.com/setsuodu/rust-videos/releases) 下载 **`rust-videos-setup-x.x.x.exe`**，双击安装。

安装向导里可勾选设为图片/视频默认打开方式。卸载走「应用和功能」或开始菜单卸载项。

## 开发构建

```powershell
cargo build --release --target x86_64-pc-windows-msvc
# 可选：本机装了 Inno Setup 6 时打安装包
iscc /DMyAppVersion=0.1.1 installer\setup.iss
```

```powershell
cargo run --release -- "D:\Videos\a.mp4"   # 打开指定文件
cargo run --release                          # 空白页
```

### 2. 播放列表数据与显示 ✅

- 【打开文件】或【文件夹】
- 【打开文件】新增的文件出现在【播放列表】根节点，已经在列表的选中开始播放
- 【打开文件夹】在根节点添加该文件夹名的节点，节点里面**禁止**播放列表出现《目录里套目录》。递归找出的视频，全部挂在该文件夹节点下。
- 图示，播放列表就按图上的绘制，禁止添加莫名其妙的其余东西。
```
播放列表
├── 【文件夹A】（2）
│   ├── a.mkv
│   └── b.mp4
└── 【文件夹B】（3）
    ├── c.wmv
    ├── d.avi
    └── e.mov
```

### 3. 播放列表项交互

列表元素支持：

- **左键拖动**：修改排序。
- **右键菜单**：
  - 播放
  - 删除（当前元素）
  - 保存列表（JSON / XML / 二进制，选一种高效格式）
  - 清空列表
  - 打开文件位置（用 Explorer 打开选中文件所在文件夹）

### 4. 播放区域右键菜单

在正在播放的视频画面上右键：

- 打开
- 全屏
- 属性

## 技术说明

- WebView2 渲染（系统解码器）
- 支持常见图片与视频格式（与 rust-photos 一致）
- Windows 优先；安装包与文件关联逻辑已从照片项目迁移并改名
